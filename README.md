Bookstore SQL Project

--Project Overview--

This project is a SQL-based Bookstore Database project created to practice and demonstrate SQL skills.

The project contains three tables:
- Books
- Customer
- Orders

The data was imported from external files into the database, and SQL operations were performed on these tables.

🗂️ Tables

Books
Stores information about books available in the bookstore.

Customer
Stores customer-related information.

Orders
Stores information about customer orders.

🔧 SQL Operations Performed

Basic SQL Operations

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- DISTINCT
- Aggregate Functions
- Filtering and Sorting

JOIN Operations

- INNER JOIN
- LEFT JOIN
- Joining multiple tables
- Retrieving data from related tables

📥 Data Import

The Books, Customer, and Orders data was imported from external files into the SQL database.

🛠️ Tools & Technologies

- MySQL
- SQL
- MySQL Workbench

🎯 Project Objective

The objective of this project is to practice SQL queries and understand how data can be retrieved and analyzed from multiple related tables.

💡 Key Learnings

- Working with relational databases
- Importing data into MySQL
- Writing SQL queries
- Filtering and sorting data
- Using aggregate functions
- Performing JOIN operations
- Working with multiple related tables
